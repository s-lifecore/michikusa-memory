# 今後の展望

## 現状の課題

| 課題 | 内容 |
|---|---|
| ソーシャル機能なし | 自分の記録を他者と共有・比較する手段がない |
| AI の精度向上余地 | 天気・季節などさらなるコンテキストを活かせていない |
| 達成感の可視化が弱い | 継続してもフィードバックが乏しい |
| ミッション体験の一方向性 | ユーザーがミッションを作る・提案する手段がない |

---

## ロードマップ

### Phase 2（短期）

- **天気・季節対応**: Weather API を組み合わせ、「雨の日ミッション」「秋限定ミッション」など状況適応をさらに強化する
- **プッシュ通知**: 「今日のミッションが届きました」など、アプリを開くきっかけを作る通知機能（インフラは整備済み）
- **ソーシャル機能**: 記録を匿名で公開・シェアし、他ユーザーの発見を見られるフィード
- **フォロー機能**: 気に入ったユーザーの冒険記録をフォロー

### Phase 3（中期）

- **アチーブメント・バッジ**: 「連続7日達成」「夜のミッション10回完了」など継続モチベーションを高める実績システム
- **ユーザー投稿ミッション**: ユーザーが自作ミッションを投稿・シェアし、コミュニティ発のお題を回せる仕組み
- **マップ可視化**: 過去の冒険ログを地図上にプロットし、「自分の行動圏」を視覚的に確認できる機能
- **GA4 統合**: ユーザー行動の分析精度向上と改善サイクルの高速化

### Phase 4（長期ビジョン）

- **AI チャットボット**: ミッション後に AI と「今日何を見つけた？」と振り返り対話できる機能
- **AR ミッション**: カメラ越しに周囲の物体を認識し、リアルタイムでお題を提示する体験
- **コミュニティグループ**: 地域・趣味単位のグループを作り、ローカルなミッションや集まりを企画できる機能

---

## 将来的なビジョン

現在のアプリは「個人の散歩体験を豊かにする」ツールだが、最終的には  

> **「街を舞台にしたゲームとして、見慣れた日常を再発見するプラットフォーム」**

を目指している。  

- AR・位置情報・AI の組み合わせで「現実世界のゲーム」化
- ローカル商店やイベントとのコラボミッションでまちおこしへの貢献
- 散歩という健康行動の継続を、ゲーム的な楽しさで自然にサポート

都市に住む人が「今日の散歩が楽しかった」と思える体験を積み重ねることで、  
街との関わり方そのものを変えていくアプリにしたい。
