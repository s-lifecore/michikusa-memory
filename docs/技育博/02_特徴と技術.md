## 技術的な特徴

### 1. コンテキスト適応型 AI ミッション

```
GPS座標 → Nominatim（OSM）でリバースジオコーディング
                ↓
現在地（国・地域） + 現地時刻（Intl.DateTimeFormat） + 明るさレベル（6段階）
                ↓
        Gemini API へプロンプトとして渡す
```

明るさは `early_morning / morning / afternoon / evening / night / dark` の6段階に分類。  
夜と朝で全く異なるミッションが生成される。また **30% の確率で時間制約付きのお題** を出す確率的バリエーション制御もプロンプトに組み込んでいる。

### 2. オフラインファースト・フォールバック設計

外部 API に依存するアプリの最大のリスクは「繋がらないと何もできない」こと。  
このアプリは以下の3層で障害を吸収する。

1. **AI 失敗時**: 100件超のフォールバックミッション（`data/fallbackMissions.ts`）から自動選択
2. **記録の保存失敗時**: localStorage に一時保存 → オンライン復帰時に Service Worker がバックグラウンド同期
3. **アルバム閲覧**: Service Worker キャッシュで過去ログをオフラインでも閲覧可能

### 3. LLM 出力の自己修復パース

Gemini API のレスポンスは Markdown コードブロックで返ってくることや、ダブルクォートが二重になるなど実運用での揺れが多い。  
これに対して専用のパース処理（`app/api/ai/mission/route.ts:190-220`）を実装し、あらゆる出力形式に対して JSON を確実に抽出できるようにした。

### 4. EXIF メタデータによる記録の信頼性担保

ギャラリーから選択した画像の EXIF データを解析し、

- 撮影時刻が「未来」になっていないか
- ミッション達成から 10 分 / 24 時間以上経過していないか
- カメラ撮影かギャラリー選択かの区別

をフラグとして記録に付与する。将来のランキング機能・不正防止の土台になっている。

### 5. 軽量認証でオンボーディング摩擦を最小化

メールアドレス不要の **英数字 ID + 7桁数字パスワード** 方式を採用。  
Firebase Anonymous Auth でセッションを管理しつつ、パスワードは bcrypt（salt=10）でサーバー側ハッシュ化する独自の2層認証構造。

### 6. 画像パイプラインの最適化

1. ブラウザ Canvas で **1024×1024・品質 80%** にクライアント側圧縮
2. 超過する場合は品質を段階的に下げて再圧縮（メモリ消費を抑制）
3. Cloudinary へアップロード → Base64 をローカルに保持しない設計

## アーキテクチャ図

```
[ブラウザ (PWA)]
      │
      ├── Next.js App Router (SSR/CSR)
      │       │
      │       ├── /api/ai/mission    ← Gemini API 呼び出し
      │       ├── /api/auth/*        ← bcrypt 認証・JWT
      │       └── /api/logs/*        ← Firestore 読み書き
      │
      ├── Firebase SDK (Firestore)   ← リアルタイム同期
      ├── Cloudinary                 ← 画像 CDN
      └── Service Worker             ← オフラインキャッシュ・バックグラウンド同期
```

## セキュリティ対策

| 対策 | 詳細 |
|---|---|
| レート制限 | ログイン: 5回/15分、サインアップ: 10回/時、ログ保存: 100回/時 |
| 入力検証 | 制御文字除去、メモ500字・場所名200字の長さ制限 |
| CSP ヘッダー | XSS・クリックジャッキング・MIME スニッフィング防止 |
| 画像ホワイトリスト | Cloudinary の自ドメインのみ表示許可 |
| 管理者 JWT | 有効期限8時間、非アクティブ30分でタイムアウト |
| GDPR 対応 | Firestore・Cloudinary・localStorage の3段階完全削除 |
