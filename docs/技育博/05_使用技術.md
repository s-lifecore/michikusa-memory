## 画像保管の詳細（Cloudinary）

散歩中に撮影した写真はすべて **Cloudinary** で管理している。

```
[ブラウザ]
  ↓ カメラ or ギャラリーから取得
  ↓ Canvas API でクライアント側圧縮（1024×1024 / 品質 80%）
  ↓ Cloudinary へ直接アップロード
  ↓ 返却された URL を Firestore のログドキュメントに保存
[アルバム表示時]
  ↓ Firestore から URL を取得
  ↓ Cloudinary CDN から最適化済み画像を配信
```

- モバイルのカメラは高解像度なため、**アップロード前にブラウザ側で圧縮**することでメモリ不足・タイムアウトを防ぐ
- 圧縮後も容量が超過する場合は品質を段階的に下げて再圧縮する動的調整ロジックを実装
- アップロード後は Base64 データを即座に破棄し、メモリを解放
- 画像 URL のホワイトリスト管理で、外部 URL の混入によるなりすまし画像表示を防止

## 認証まわり

| 技術 | 用途 |
|---|---|
| **Firebase Anonymous Auth** | セッション管理（匿名UID でブラウザとユーザーを紐付け） |
| **bcryptjs** | ユーザーパスワードのサーバーサイドハッシュ化（salt=10） |
| **JSON Web Token (JWT)** | 管理者ダッシュボードのセッション管理（有効期限 8 時間） |
